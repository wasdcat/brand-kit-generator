# Creating a post

The *Creation* area is the day-to-day workbench. It has two blocks: the choice of building blocks on top, the text below.

## Selection

Four selectors, each with an *Edit →* link that jumps straight to the matching area:

| Field | Chooses |
| --- | --- |
| **Product** | Which brand or show |
| **Template** | Which layout |
| **Font set** | Which font variations |
| **Colour set** | Which colours |

Under the colour set selector the seven colours of the chosen set appear as small bars. A quick glance to confirm you picked the right one.

The four are independent of each other. Changing the colour set leaves template, product and text untouched.

## Content

Five fields for the piece at hand:

- **Title** — the main statement. The character count sits above the field.
- **Subtitle** — second level, a guest or a subtitle
- **Description** — running text, the smallest text level
- **Tag 1** and **Tag 2** — short markers, usually in capitals, shown as coloured chips

### "not used in the template"

Next to a field you may see *not used in the template* in amber. It means the template currently chosen has no place for that value. You can still enter something — it simply is not shown.

That is intent, not a fault. A lower third for video shows a title and a tag; a title card for a feed post also has room for a subtitle and a description. Whatever you typed is kept and reappears the moment you pick a template that uses it.

> [!TIP] Which fields a template uses
> The *Template* area lists every placeholder under *Placeholders in this template*. The highlighted ones are used, the faint ones are not.

### Empty fields disappear

An empty field leaves no gap. Leave *Tag 2* blank and the second chip vanishes entirely — along with its spacing, not as an empty box. The same goes for every text placeholder and for logos.

That lets the same template carry a dense or a sparse post without being adjusted.

### Text that is too long

Some templates limit the number of lines, the title to two say. Anything beyond that is cut for the export at a word boundary and given a real `…` in the file.

You can see the cut in the preview already. If you do not like the shortened title, shorten it yourself rather than leaving it to the tool.

## The preview keeps up

Every keystroke reaches the preview after about a fortieth of a second. You type and see the result, with nothing to confirm.

What is rendered is always the format currently chosen. Switching format rebuilds it — which is why the status dot in the top left blinks amber for a moment.
